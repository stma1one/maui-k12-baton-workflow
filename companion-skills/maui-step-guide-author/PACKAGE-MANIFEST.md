# Package Manifest

Package: MAUI Step Guide Author Skill (Source-Grounded Learning Books)
Version: 1.2.0
Status: ready-to-install

## Purpose

Authoring step-by-step .NET MAUI learning books for new and existing projects. Guides are source-grounded, use small visual and MVVM blocks, can generate HTML visual models when no emulator is available, and validate the final HTML/PDF book before publication.
